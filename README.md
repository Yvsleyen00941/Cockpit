# Control Center

Your Mac, at your fingertips. The iPad next to your keyboard becomes a
control surface:

- **Contextual keys** follow whatever is in front: Safari, Xcode, Notion,
  Terminal, Finder, calls.
- **Live dashboards** show your trading bot, WHOOP recovery, calendar,
  Focus, music and the Mac's vitals.
- **The day, planned:** a Morning Brief, a top-3, Pomodoro and deep-work
  timers.

It has two native apps and no third-party dependencies:

- **Control Center** for iPad, plus a compact iPhone version with widgets,
  a Live Activity, Siri and Control Center controls.
- **ControlCenter Helper**, a macOS menu-bar app that owns all the data and
  does the work.

They talk over the local network (or the USB-C cable) with end-to-end
encryption. Nothing touches a cloud.

| Page | Shows |
|---|---|
| **Home** | Four quadrants: bot, recovery, Focus & schedule, Mac & media |
| **Brief** | 06:00–10:00: greeting, Antwerp weather, recovery, overnight trades, agenda, top 3, **Start the day** |
| **Bot** | P&L chart, positions, trade log, health, pause/resume/close-all |
| **Study** | Lecture-aware: Pomodoro, next lecture, quick-launch and study shortcut keys |
| **Meeting** | Mute, camera, hand, share, leave, for whichever call app is open |
| **Mac** | CPU per core, memory pressure, battery, processes, app switcher, window tiling |
| **Markets** | PortTracker net worth, movers, turbos near knockout |
| **Safari, Xcode, Notion, Terminal, Finder** | The right keys for that app, switched to automatically |

How it all fits together, in short:

- One hub on the Mac holds all the state.
- Each data source runs only while a screen needs it.
- One action language drives every button, widget, Siri phrase and script.
- A rule engine picks the page from the app, URL, calendar, Focus and timers.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the full picture.

## Requirements

- Mac with macOS 14 or later (the helper)
- iPad with iPadOS 17 or later; iPhone with iOS 17 or later. Control Center
  controls need iOS 18.
- Xcode 16 or later. The project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
  from `project.yml`, and the generated project is committed.

## Build and run

1. **Signing:** `Config/Base.xcconfig` uses team `34LM5DW4G4` with automatic
   signing. To use another team, create `Config/Local.xcconfig` (it's
   gitignored):

   ```
   DEVELOPMENT_TEAM = ABCDE12345
   ```

   The bundle IDs are `be.yorben.controlcenter` (with `.widgets` and
   `.helper`), and the App Group is `group.be.yorben.controlcenter`.
2. **Mac helper:** run the `ControlCenterHelper` scheme from Xcode to try it.
   To install it for real, run:

   ```sh
   Tools/install-helper.sh
   ```

   This builds a signed Release copy, puts it in `/Applications` (the only
   place it registers itself to start at login), and launches it.
3. **iPad:** select the `ControlCenter` scheme and your iPad, then Run. On
   first launch, pick your Mac and type the 6-digit code it shows. After that,
   connecting is automatic. **Explore the demo first** runs the whole app on
   simulated data, with no Mac needed.
4. **iPhone:** the same scheme, run on your iPhone. It has compact pages,
   widgets, the Live Activity and controls.

If you changed `project.yml`, regenerate with `xcodegen generate`.

> **Free Personal Team:** apps signed this way stop launching after
> 7 days, so re-run them from Xcode weekly. Live Activity *push* updates need
> a paid membership; without it, the Live Activity still updates whenever the
> iPhone app runs, and its timer counts down on its own.

## Permissions (on the Mac)

The helper's **Preferences → Permissions** shows each item with a **Grant**
button. The menu bar also warns about anything that's missing.

| Permission | Used for |
|---|---|
| Accessibility | Keystrokes, text, window tiling, media keys, call controls, window titles |
| Automation | Spotify, Music, Safari and Chrome (current tab URL), Terminal, System Events. macOS asks per app, the first time. |
| Calendar | Agenda, next event, lecture detection |
| Reminders | Optional: mirrors your top 3 to Reminders |
| Full Disk Access | Reading which Focus is active (`~/Library/DoNotDisturb`) |
| Input Monitoring | Recording keystroke macros |

## Integrations

Every integration has its own pane in the helper's Preferences and a status
dot in the menu bar.

- **Trading bot:** simulated until you point it at your bot. The contract
  (`GET /status`, optional `/events` and `/pnl`, `POST /pause`, `/resume`
  and `/close-all`, field mapping, webhook) is in
  [docs/BOT-API.md](docs/BOT-API.md).
- **WHOOP:** create an app on the [WHOOP developer dashboard](https://developer.whoop.com)
  with redirect URI `http://localhost:8080`, then paste its client ID and
  secret into **Preferences → WHOOP**, click **Save**, then **Connect WHOOP**. This uses the
  v2 API (v1 was retired), with the scopes recovery, cycles, sleep, profile,
  body measurement and offline. Tokens refresh themselves and are stored in
  the Keychain.
- **Focus:** macOS has no API for turning Focus on or off, so the helper runs
  Shortcuts. In the Shortcuts app, create one shortcut per mode named exactly
  `Focus: <Mode>`. For example, `Focus: Work` holds a single **Set Focus →
  Work → On** action. Also create `Focus: Off` with **Turn Focus Off**. The
  helper finds them automatically; **Preferences → Focus** lists what it
  detected.
- **Calendar and Reminders:** EventKit, all calendars, live updates.
- **Music:** Spotify and Apple Music, with artwork. Track changes arrive
  instantly, and the players are only queried while they're running.
- **Weather:** Open-Meteo, no key needed. The location is Antwerp by
  default; change it in **Preferences → Brief & Timers**.
- **PortTracker:** net worth, movers and turbos from `GET /api/market/standby`.
  Set the base URL and an auth header in **Preferences → PortTracker**.
  PortTracker authenticates with a Supabase session, so the header is
  currently a `Cookie`. A token path on that route would make this robust.
- **Git:** status, pull, push, fetch, commit-all and stash for the
  repositories you add under **Preferences → Git**. The Xcode page picks up
  the repository of the open project.

## Beyond the iPad

- **Widgets:** Trading Bot, Recovery and Desk, on the Home Screen and Lock
  Screen. The buttons are interactive, so you can pause the bot or start a
  focus block without opening the app.
- **Live Activity (iPhone):** the bot's P&L, your recovery and the running
  timer, on the Lock Screen and in the Dynamic Island.
- **Control Center controls (iOS 18):** Bot, Mic, Focus Session, Start the
  Day.
- **Siri and Shortcuts:**
  - "Open trading view on my iPad with Control Center"
  - "Pause the bot with Control Center"
  - "How's my bot doing in Control Center"
  - "Start a focus session with Control Center"
  - "Good morning Control Center"
  - "Mute my Mac with Control Center"
- **USB-C:** plug the iPad in and trust the Mac. The same encrypted link then
  runs over the cable, and the top bar shows **USB-C**. It falls back to Wi-Fi
  on its own when you unplug.
- **Several Macs:** pair each one. The app connects to whichever is around,
  and **Settings → Connection** lets you pick.
- **Local API:** scripts, cron jobs, Raycast or your bot can drive the hub
  over `127.0.0.1:52521`:

  ```sh
  TOKEN=$(defaults read be.yorben.controlcenter.helper localAPIToken)
  curl -H "Authorization: Bearer $TOKEN" -X POST localhost:52521/v1/toast -d '{"title":"Build done","style":"success"}'
  curl -H "Authorization: Bearer $TOKEN" -X POST localhost:52521/v1/scene -d '{"id":"startDay"}'
  curl -H "Authorization: Bearer $TOKEN" -X POST localhost:52521/v1/action -d '{"type":"media","command":"next"}'
  curl -H "Authorization: Bearer $TOKEN" -X POST localhost:52521/v1/navigate -d '{"page":"bot"}'
  ```

  The routes are `GET /v1/health`, `GET /v1/state` and `GET /v1/workspace`,
  plus `POST` to `/v1/action`, `/v1/scene`, `/v1/navigate`, `/v1/toast`,
  `/v1/bot/event` and `/v1/bot/status`.

## Customising

- **On the iPad:** tap the pencil in the top bar to drag tiles, resize them,
  or edit any key. Every key is a `ButtonAction`: key combos (AZERTY-safe), text with
  `{{date}}`, `{{url}}` and `{{clipboard}}` templates, AppleScript, shell,
  Shortcuts, window tiling, media, call controls, timers, git, scenes, and
  macros, which you can record on the Mac. **Settings** covers context rules
  (which page shows when), app mappings, scenes, the bottom strip, Pomodoro
  lengths and the Morning Brief window.
- **By hand:** the whole layout lives in
  `~/Library/Application Support/ControlCenter/workspace.json`, which the
  helper watches. Save it and every device updates. **Settings → Export &
  Import** shares it as JSON.

## Development

```sh
cd Packages/ControlCenterKit && swift test    # protocol, crypto, context engine, grid, simulation
```

| Switch | Effect |
|---|---|
| `-CCDemo` / `-CCDemoHome` / `-CCPage <id>` | App launch arguments: demo hub, start on Home, pin a page |
| `CC_INSTANCE=test` | Run a second, isolated helper next to your real one: its own identity, data, random port, and secrets in a file instead of the Keychain |
| `CC_E2E=1` | Helper without prompts, sounds or login item, logging to stdout |
| `CC_PRINT_PAIRING_CODE=1` | Print the pairing code to stdout |

The wire protocol is in [docs/PROTOCOL.md](docs/PROTOCOL.md).

## Notes

- **iPad Pro (M1) has no Taptic Engine.** Keys use a soft key-click sound and
  a light acknowledgement glow when the Mac confirms. iPhones also get
  haptics.
- **Google Meet** controls work while its tab is in front, since Meet has no
  app.
- **The USB-C bridge** follows Apple's usbmux protocol but hasn't been tested
  against a physical iPad yet. Wi-Fi remains the default path.
